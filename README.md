# Консольная утилита на Bash

Практическая работа 7 по операционным системам. Скрипт выводит пользователей с домашними каталогами и список процессов. Аргументы разобраны через GNU getopt, действия вынесены в отдельные функции.

Для запуска требуется Linux с Bash, GNU getopt, getent, ps и GNU coreutils.

```bash
chmod +x system_info.sh
./system_info.sh --help
./system_info.sh --users
./system_info.sh --processes
./system_info.sh -u -p --log 'output list.txt' --errors errors.txt
```

| Параметры | Действие |
| --- | --- |
| `-u`, `--users` | Пользователи и домашние каталоги, сортировка по имени |
| `-p`, `--processes` | Запущенные процессы, сортировка по PID |
| `-h`, `--help` | Справка с остановкой обработки действий |
| `-l PATH`, `--log PATH` | Запись stdout в файл с заменой содержимого |
| `-e PATH`, `--errors PATH` | Запись stderr в файл с заменой содержимого |

Пути с пробелами заключаются в кавычки. Параметры вывода и ошибок применяются ко всем выбранным действиям. При повторном указании пути используется последнее значение. Для общего файла stdout и stderr используется один открытый дескриптор.

Перед открытием файла проверяется доступность пути. Ошибки команд getent, ps и форматирования заменяются сообщениями утилиты. Код завершения 0 соответствует успешной работе, 1 — ошибке доступа или выполнения, 2 — ошибке аргументов, 127 — отсутствию getopt.
